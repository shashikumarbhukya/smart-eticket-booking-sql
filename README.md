# Smart E-Ticket Booking & Analytics System

A SQL-based database project for managing online ticket booking, seat availability, payments, booking history, user funnel tracking, and revenue analytics.

## Objective

The objective of this project is to design a relational database for an online e-ticket booking platform and analyze user behavior, bookings, payments, and event performance using SQL.

## Features

- User profile management
- Event listing and seat availability tracking
- Ticket booking and payment status management
- User booking history
- Revenue analysis by event
- User funnel analysis
- Conversion rate analysis
- Event demand and booking trend analysis

## Tech Stack

- SQL / MySQL
- GitHub

## Database Tables

1. Users
2. Events
3. Seats
4. Bookings
5. Payments
6. EventLogs

## Key SQL Concepts Used

- Primary Keys
- Foreign Keys
- Joins
- Aggregate Functions
- GROUP BY
- ORDER BY
- CASE WHEN
- Funnel Analysis
- Conversion Analysis
- Revenue Analysis

## Sample Business Questions Answered

- Which seats are available for an event?
- What is the booking history of a user?
- Which event generated the highest revenue?
- Which event received the highest bookings?
- What is the user conversion rate from event view to payment success?
- Where are users dropping in the booking funnel?
